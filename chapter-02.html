也就是说音名和唱名不是一一对应的？

没错，在绝大多数日常演奏和演唱（首调唱名法）中，音名和唱名确实不是一一对应的。

你可以把它们理解为“身份证号”和“岗位头衔”的关系：

音名（C、D、E、F、G、A、B）＝ 身份证号（绝对固定）

无论在什么曲子里，钢琴上中央 C 那个琴键（频率约 261.6 Hz），或者吉他 5 弦 3 品那个音，它的物理振动频率是不变的，永远叫 C。

唱名（Do、Re、Mi、Fa、Sol、La、Si）＝ 岗位头衔（相对流动）

谁当主角（主音），谁就坐上 Do（1） 的位置，后面的音按顺序排成 Re、Mi、Fa、Sol、La、Si。

具体对应关系一览

在不同大调下，“头衔”是如何重新分配给不同“人”的：

唱名（岗位头衔）1 (Do)2 (Re)3 (Mi)4 (Fa)5 (Sol)6 (La)7 (Si)
C大调CDEFGAB
D大调DE#FGAB#C
F大调FGAbBCDE

在 C 大调里：C 担任 Do，G 担任 Sol。

在 D 大调里：D 升职担任 Do，原来的 C（升半音后变成 #C）退居二线去担任 Si（7）。

在 F 大调里：F 担任 Do，原来的 C 变成了 Sol（5）。

唯一的例外：两种唱名法体系

在实际音乐学习中，之所以有人会觉得它们“一一对应”，是因为存在两种不同的记谱和识谱体系：

首调唱名法（Movable-Do）—— 流行音乐、吉他弹唱、简谱常用

规则：就是上面说的，Do 跟着调跑（1=C 就把 C 唱 Do，1=D 就把 D 唱 Do）。

优点：极大方便了转调和扒谱。只要你记住了一首歌的旋律走向（比如《小星星》的 1 1 5 5 6 6 5），无论换成什么调，你脑子里的唱名完全不用变，直接在乐器上平移位置就能弹出来。

固定调唱名法（Fixed-Do）—— 钢琴、小提琴、古典五线谱常用

规则：强制把 C 永远唱作 Do，D 永远唱作 Re，E 永远唱作 Mi……哪怕曲子是 D 大调，看到音名 D 依然嘴里唱 Re。

优点：视奏极其复杂、频繁转调的古典乐谱时，看到五线谱上的位置就能瞬间反射出手指该按哪个物理琴键，不需要在脑子里做“换算”。

总结来说，物理音高（音名）是死板的，而音乐听感（唱名）是相对的——我们人耳识别旋律，靠的正是音与音之间的相对比例关系，而不是绝对频率。

MARGIN NOTES · 新增旁注

NOTE 02.01 · 新增

音级是什么

把音阶从主音开始编号：第一级、第二级……。本书的大调首调例子里，对应 1、2、3……和 Do、Re、Mi……。

NOTE 02.02 · 新增

校准｜一个 C 不只有一个频率

C 是音级名称，必须标明八度才能定位具体音高。常用 A4=440 Hz 调音时，中央 C（C4）约 261.63 Hz；标准调弦吉他第 5 弦第 3 品为 C3，约 130.81 Hz，比中央 C 低一八度。

NOTE 02.03 · 新增

八度是什么

一个 C 到相邻的高音 C 是一个八度；高音的频率是低音的两倍。名字相同，高低不同。

NOTE 02.04 · 新增

校准｜体系不是乐器专属

学钢琴也可以用首调，唱流行歌也可以用固定调。体系与教学传统和训练目的有关，不能仅按乐器划分。固定调遇升降音的具体读法也有不同惯例。

NOTE 02.05 · 新增

记忆｜换角色，不改姓名

在 F 大调里，C 仍然叫 C，但承担第五级的角色。首调唱 Sol（5）；固定调仍以 Do 称呼 C。

KEEP THREE THINGS · 新增速记

合上这一页，记住三件事。

  1. 音名像姓名，首调唱名像角色。
  2. 首调 Do 随调走；固定调 C 对应 Do。
  3. 音名 + 八度，才能定位具体音高。
翻卡自测 · F 大调中，C 用首调唱什么？

Sol（5）。F、G、A、B♭、C，C 是第五级。
